# Contributing to ReflexBench

Contributions should improve a released public object: a scenario, observer-depth prompt, scoring boundary, artifact manifest, audit, figure, or documentation route.

## Scenario proposal

A scenario proposal must include:

1. A concrete decision setting and the actor whose output enters the setting.
2. OD-0, OD-1, OD-2 and OD-n prompts that test different causal depth rather than longer prose.
3. A scoring rubric for each prompt with observable pass, partial and fail conditions.
4. The reflexive mechanism: capacity, incentives, strategic adaptation, data feedback, institutional response, or equilibrium instability.
5. A counterexample that would show the scenario is observer-invariant or redundant with an existing scenario.
6. Provenance and license information for any external material.

## Artifact mismatch

Report the exact path, expected state, observed state and a minimal reproduction command. The reported workshop study size and the file-level coverage of this GitHub mirror are separate facts; see `PUBLIC_ARTIFACT_MANIFEST.json`.

## Public boundary

Do not post credentials, private logs, customer data, restricted datasets, identity-sensitive review material, or non-public paper versions. Security-sensitive findings belong in the private reporting route defined by the repository owner, not a public issue.

## Acceptance

A contribution is accepted when it is public-safe, licensed, specific, reproducible from the committed artifact, and does not broaden a claim beyond the released evidence.
